background:
  problem: 스마트 아파트에 연동된 SmartThings가 실제 생활에서 어떻게 쓰이는지 검증하고, 낮은 연동률의 원인을 찾아 개선해야 했습니다.
  context:
    - title: 세 개 단지
      body: 래미안 리더스원, 송도 더샵 트리플타워, 효창파크푸르지오 입주민을 대상으로 같은 절차로 조사했습니다.
    - title: 낮은 연동률
      body: 스마트 아파트에 SmartThings가 연동돼 있어도 실제로 연결해 쓰는 가구는 많지 않았습니다.
    - title: 실사용 검증
      body: 설문만으로는 알기 어려운 실제 생활 속 사용 장면을 확인해야 했습니다.
approach:
  heading: UX 리서처로 — 설계, 운영, 분석, 개선까지 직접
  items:
    - title: 리서치 설계
      body: 조사 목적과 대상을 정하고, 모집 공고·스크리너·쿼터부터 조사 가이드·설문지·좌담회 가이드·홈 비짓 가이드까지 리서치 도구를 직접 설계했습니다.
    - title: 파일럿 → 2차 본조사
      body: 1차 파일럿 조사로 방법을 검증한 뒤, 방법을 개선하고 사용성 조사 인력을 늘려 2차 사용성 조사를 진행했습니다.
    - title: 세 단지 운영
      body: 리서치 에이전시 Ipsos Korea와 함께 세 단지에서 같은 절차로 모집부터 가정 방문까지 운영했습니다.
    - title: 분석과 개선
      body: 정량·정성 결과를 분석해 인사이트를 정리하고, 개선 항목을 도출해 제품에 적용했습니다.

      - title: 직접 써 보게 하기
        body: 앱 가입·월패드 연동 후 기기 제어·알림·모드·자동화·가족 초대 5개 과제를 3일간 수행하게 했습니다.
      - title: 정량 → 정성 → 관찰
        body: 설문(단지별 약 30세대)에서 선별해 좌담회(2그룹 × 4세대)로, 다시 선별해 가정 방문으로 좁혀 들어갔습니다.
      - title: 반복 가능한 프로세스
        body: 같은 절차를 세 단지에 적용할 수 있는 반복형 리서치 프로세스로 정립했습니다.
  - label: 인사이트 → 개선
    heading: 찾아낸 허들을 개선 항목으로
    visual:
      id: apt-insight-map

      description: 리서치 인사이트와 개선 항목 매핑 (적용 / 도출)
    points:
      - title: 연동 간소화 적용
        body: 가장 큰 허들이던 연동·온보딩 과정을 간소화했습니다.
      - title: 프리셋 모드·자동화 적용
        body: 사용 장면을 떠올리기 어려운 모드·자동화에 강력 환기·외출 모드·미세먼지 자동화 같은 선호 프리셋을 제공했습니다.
      - title: 추가 개선 항목 도출
        body: 가족 공유·멤버 설정, 알림 기본 On, 방별·아파트 단위 조명 그룹화, 홈 화면 구조 개선을 개선 항목으로 도출했습니다.
      - title: 커뮤니티 시설 알림
        body: 입주민은 헬스장·수영장 같은 커뮤니티 시설 알림도 기대했습니다.
impact:
  metrics:
    - value: 8% → 12%

    - value: 40~50% → 80~90%
      label: 자체 앱이 없는 단지의 연동률
  results:
    - 프리셋 기반 모드·자동화, 연동 간소화 등 개선 적용

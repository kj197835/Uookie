background:
  problem: 기존 강자가 있는 빌딩 관리(BMS) 시장에 후발 주자로 들어가면서, 실제 공간을 정확하게 보여주는 확실한 차별점이 필요했습니다.
  context:
    - title: 후발 주자
      body: 빌딩 관리 시장에는 이미 자리 잡은 솔루션이 있어, 기능 목록만으로는 차별화가 어렵습니다. 건물을 실제 공간 그대로 정확하게 보여주고 그 위에서 바로 관리하는, 공간 중심의 차별화된 솔루션이 필요했습니다.
    - title: 대규모 운영
      body: 빌딩 운영자는 많은 층과 공간, 많은 기기를 동시에 관리해야 합니다.
    - title: 이종 기기
      body: B2B IoT 기기와 B2C(SmartThings) 기기, 로봇, 선박, 차량까지 서로 다른 대상을 한곳에서 다뤄야 합니다.
approach:
  heading: B2C에서 검증한 공간 경험을 B2B 운영 효율에 맞게 재설계
  items:
    - title: 초기부터 참여
      body: SmartThings Pro 초기부터 참여해, B2C Map View 경험을 B2B로 확장하는 방향을 잡았습니다.
    - title: 운영자 효율 중심
      body: 대규모 빌딩 운영자의 효율에 맞게 편집·필터 기능을 더해 고도화했습니다.
    - title: 공간을 플랫폼으로
      body: 3D 맵을 IoT 기기만이 아니라 로봇·선박·자동차·재실 데이터까지 올릴 수 있는 공통 공간으로 설계했습니다.
    - title: 전시로 가치 전달
      body: CES 2025 부스 콘셉트와 전시 화면을 직접 설계·운영해, 차별화 기능을 현장에서 보여 줬습니다.

    points:
      - title: 2D 도면 → 3D 맵 자동 변환
        body: 건물의 2D 도면을 AI로 분석해 3D 맵으로 자동 변환합니다. 운영자는 목록이 아니라 실제 공간 구조 위에서 기기를 봅니다.
      - title: B2B·B2C 기기를 한 공간에
        body: B2B IoT와 B2C(SmartThings) 기기를 같은 3D 맵에 배치·관리하고, 편집·필터 기능으로 대규모 빌딩에 맞게 고도화했습니다.
      - title: 재실 히트맵
        body: 히트맵 센서(재실 감지)와 CCTV(혼잡도 감지)로 3D 맵에 재실 히트맵을 구현하고, 에너지 절감 솔루션에 적용했습니다.
      - title: Node-RED 기반 B2B 자동화
        body: 노드를 선으로 이어 기기·조건·동작을 연결하는 Node-RED 방식의 자동화 도구로, 복잡한 B2B 자동화 흐름을 시각적으로 만들 수 있습니다.

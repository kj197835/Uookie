  problem: A feature-rich, complex B2B management solution had to become easy for anyone to use, and repetitive UI-guide production had to shrink.

    - title: Complex B2B features
      body: SmartThings Pro has many features for running buildings and spaces, so operators face a steep learning curve just to find and use what they need.
    - title: Repetitive UI guides
      body: Every PRD change meant designers rebuilt the UI guide by hand, slowing delivery and weakening design–development consistency.
    - title: Multilingual quality
      body: For a global solution, inconsistent terms and tone in automatic translation erode trust in the product.
approach:
  heading: Applying AI to both the experience and the way we work — not just as a feature
  items:
    - title: GenAI chatbot — replace and extend features
      body: Designed the top-level solution architecture and conversational UI of a generative-AI chatbot that replaces and extends SmartThings Pro features through conversation.
    - title: AI translation — rules first
      body: Built guidelines for automatic multilingual translation — core principles, tone and manner, format and localization rules, and a glossary — so it behaves consistently.
    - title: AI design automation — PRD to UI guide
      body: Planning and building a system, with Claude and Figma MCP, that reads PRDs in Confluence and Jira and generates Figma UI guides automatically.
    - title: AI shift for the team
      body: Led the adoption and operation of AI tools for the UX group (Gemini, ChatGPT, Claude, Midjourney, Firefly and more).

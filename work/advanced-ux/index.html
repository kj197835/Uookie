CH.2 · Mobile UX

Advanced UX — 새 폼팩터 USP 발굴

무선사업부 (MX)

갤럭시 S8의 새 폼팩터에 맞춰 SW 내비게이션·전면 카메라 펀치홀 등 새로운 UX를 발굴하고, 특허로 만들고, 실제 S8에 적용했습니다. 콘셉트·디자인·실제 프로토타입을 1인 3역으로 맡았습니다.

기간
2014.04 – 2016.09
역할
콘셉트 발굴, UX 디자인, 안드로이드 실제 프로토타이핑 (1인 3역)

배경 · 문제

갤럭시 S8의 새 폼팩터 — 더 길어진 화면과 물리 홈 키가 사라진 SW 내비게이션 — 에 맞는 차별화 경험(USP)을 발굴하고, 구현 가능성까지 빠르게 검증해야 했습니다.

새 폼팩터

화면이 길어지고 물리 키가 화면 속 SW 키로 바뀌면서, 기존 화면과 입력 방식을 그대로 옮겨서는 새 폼팩터의 장점을 살리기 어려웠습니다.

구현 가능성

콘셉트가 좋아도 실제로 동작하지 않으면 제품에 채택되기 어렵습니다.

내 역할 · 접근

개발에서 UX로 — 콘셉트부터 동작하는 프로토타입까지 한 번에

역할: 콘셉트 발굴, UX 디자인, 안드로이드 실제 프로토타이핑 (1인 3역)

  1. 01

    1인 3역

    개발에서 UX로 전환해, 콘셉트 제안부터 디자인과 실제 동작 프로토타입까지 한 번에 검증하는 Advanced UX 그룹에서 활동했습니다.

  2. 02

    실제 프로토타입

    Android Studio(Java)로 실제 프로토타입을 만들고, Voice Avatar·Implicit Voice·Camera Vision 등 선행 과제를 수행했습니다.

  3. 03

    TRIZ 방법론

    TRIZ 방법론으로 UX 콘셉트와 특허를 발굴했습니다.

핵심 설계 · S8 새 폼팩터

새 폼팩터 → UX 발굴 → 특허 → 제품 적용

  1. 1

    새 폼팩터의 등장

    갤럭시 S8은 화면이 더 길어지고 물리 홈 키 대신 화면 속 SW 내비게이션을 쓰는 새 폼팩터였습니다.

  2. 2

    SW 내비게이션 UX → S8 적용

    화면 특성에 맞춰 내비게이션 바가 숨김·투명·불투명으로 바뀌는 Flexible SW Navigation Key를 발굴해 특허(US10852944)로 등록하고, 갤럭시 S8에 적용했습니다.

  3. 3

    전면 카메라 펀치홀 UX

    화면 안으로 들어온 전면 카메라 영역을 활용하는 펀치홀 USP 콘셉트를 발굴했습니다.

  4. 4

    발굴에서 특허, 제품까지

    길어진 화면의 멀티 윈도우 UX와 듀얼 디스플레이 카메라 UX도 특허로 등록했고, 듀얼 디스플레이 카메라는 갤럭시 폴드 USP로 적용됐습니다.

결과 · 임팩트

  • 갤럭시 S8 새 폼팩터에 맞는 Flexible SW Navigation Key 발굴 → 특허 등록(US10852944) → 갤럭시 S8 적용
  • 전면 카메라 펀치홀 USP 콘셉트 발굴
  • 듀얼 디스플레이 카메라 UX 발굴, 갤럭시 폴드 USP 적용 (US10681263)

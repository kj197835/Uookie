Case 04 · Spatial IoT

CH.4 · 공간 UX 고도화

SmartThings Map View

3D 도면 기반 스마트홈

아이콘 목록 대신 실제 집 구조의 3D 도면 위에서 기기를 보고 제어하는 SmartThings 경험을 제안하고, 스마트 아파트부터 적용했습니다.

기간
2023.01 – 2023.12
역할
UI/UX 디자인 리드 (2022년 선행 콘셉트 제안·채택 후 구현)
수상
2024 iF Design Award

배경 · 문제

아이콘 목록 중심의 기기 제어로는 집 안 기기의 상태와 위치를 직관적으로 파악하기 어려웠습니다.

위치가 사라진 목록

기기가 목록으로만 보이면, 어느 방의 어떤 기기인지 이름으로 기억해야 합니다.

도면 준비의 부담

사용자가 집 구조를 직접 그리게 하면 첫 사용부터 허들이 생깁니다.

스마트 아파트 연결

스마트 아파트는 설계 도면과 설치 기기 정보가 있어, 이를 활용할 여지가 있었습니다.

내 역할 · 접근

선행 콘셉트에서 실제 앱 출시까지

역할: UI/UX 디자인 리드 (2022년 선행 콘셉트 제안·채택 후 구현)

  1. 01

    2022 콘셉트 제안·채택

    SmartThings를 실제 집 구조의 3D 도면 위에 표현하는 콘셉트를 제안해 채택됐습니다.

  2. 02

    2023 앱 구현

    채택된 콘셉트를 UI/UX 디자인 리드로서 SmartThings 앱에 구현했습니다.

  3. 03

    건설사와 협의

    신축 건설사와 협의해 모든 방까지 연동하고, 공간별 기기 자동 배치를 적용했습니다.

핵심 설계 · 맵 뷰 생성 흐름

도면 자동 생성 + 기기 자동 배치

  1. 1

    단지·평형 자동 선택

    SmartThings와 연동된 스마트 아파트는 단지와 평형을 자동으로 찾아 도면을 불러옵니다. (②·③)

  2. 2

    3D 도면 자동 생성

    불러온 평면도로 실제 집 구조의 3D 도면을 자동으로 만듭니다. (④)

  3. 3

    기기 자동 배치

    현관·거실·주방의 IoT 기기를 도면 위 제자리에 자동으로 배치합니다. (⑤)

  4. 4

    모든 방으로 확장

    신축 건설사와 협의해 모든 방까지 연동하고, 공간별로 기기를 자동 배치합니다.

핵심 설계 · 스마트 아파트 적용

스마트 아파트에 Map View를 먼저 적용

  1. 1

    스마트 아파트부터 적용

    SmartThings를 적용한 스마트 아파트에 Map View 기반 홈 IoT 솔루션을 선보였습니다. (2023.07.06 발표)

  2. 2

    아마존보다 약 4개월 앞서

    아마존 알렉사 Map View(2023.11.15 보도)보다 약 4개월 앞서 발표했습니다.

  3. 3

    IoT 솔루션 최초

    IoT 솔루션 최초로 2D 도면 → 3D 도면 자동 변환과 기기 자동 배치를 구현했습니다.

  4. 4

    2024 iF Design Award

    SmartThings Map View로 2024 iF Design Award를 수상했습니다.

결과 · 임팩트

  • 최초IoT 솔루션 2D→3D 자동 변환·기기 자동 배치
  • 약 4개월아마존 알렉사 Map View보다 앞선 발표
  • IoT 솔루션 최초로 2D→3D 자동 변환·기기 자동 배치 구현
  • 2023.07.06 스마트 아파트용 발표, 아마존 알렉사 Map View(2023.11.15 보도)보다 약 4개월 앞섬
  • 2024 iF Design Award
